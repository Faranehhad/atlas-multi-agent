# Atlas — Multi-Agent Travel AI

A LangGraph-based multi-agent AI assistant that uses an LLM to understand and decompose user requests, routes tasks to specialized agents, retrieves information from public APIs, and synthesizes the results into a final answer.

## Planned Features

- FastAPI API
- LangGraph orchestration
- LLM-based query analysis
- Multi-question decomposition
- Specialized AI agents
- Weather information
- City and travel information
- GitHub information
- Public API integrations
- Structured LLM outputs
- Automated tests
